# 2026-10-06 — 첫 자동 측정 v1

19개 사례의 최초 측정이다. [원시 JSON](baseline.json)과 [당시 표](table.md)를 보존한다.
제품 동작과 입력은 현재 [v2 기준선](../2026-10-06-baseline-v2/README.md)과 같다.

v1 표는 사각형 교집합을 합쳐 표시하고 명령 성공과 보존을 따로 표기하지 않았다.
따라서 겹침 합계를 품질 점수로 쓰거나, `add-then-remove`의 보존 통과를 명령 성공으로 읽으면 안 된다.
v2에서 방법과 표시를 보완했으며 당시 기록은 덮어쓰지 않았다. v1/v2의 결과 XML 19개 SHA-256은 모두 같다.

[실제 렌더링 12개 비교](comparison.html), [렌더링 조건](rendered.json), [Kiro 지표 구현 보고](kiro-metrics-report.md)를 함께 남긴다.
이 디렉터리의 `test-output.txt`는 통합 검사 추가 전 115개 통과 기록이며, 최신 116개 실행은 v2에 있다.
