## 확인한 결과와 의미

- 입력 4개 × 원본/계층/좌→우/서비스 추가와 추가 명령 3개, 총 **19개**. 측정 도구 실행 실패는 0개다.
- 계층·좌→우·서비스 추가 **12개 모두 원본 내용 셀 보존 실패**다. ID 누락에는 ID 재발급이 포함된다. 이를 전부 객체 삭제 수로 해석하지 않는다.
- `example1`: 원본 vertex 91/edge 29 → 계층 정렬 vertex 57/edge 2. ID 유지와 선 표현 보존을 동시에 실패했다. 서비스 추가도 edge 2로 줄었다.
- 보존 합성 사례: 메모·끝점 선이 사라지고 기존 서비스 ID가 변경된다. 추가→원래 ID 삭제는 실패한 뒤 원본으로 롤백된다. 삭제 단독과 의도한 오류의 롤백은 기대 검사에 통과했다.
- `example1` 원본 사각형 교집합: 부분 6쌍/완전 포함 285쌍/동일 0쌍. 포함 배치를 자동으로 오류라고 판단하지 않는다.
- `test2` 원본: 부분 0/포함 77/동일 76. 11개 서비스 아이콘과 7개 그룹이 각각 같은 위치·크기에 쌓여 있다. “부분 겹침 0”이 안전한 배치를 뜻하지 않는다.
- 멀티 AZ 합성 원본의 명시 흐름 역방향 0/4, 대응 위치 편차 0/3. 손으로 만든 입력의 기준값이다. 레거시 변환은 해당 ID가 없어 두 지표를 null로 남겼다.

세부 [측정 표](table.md)와 [원시 JSON](baseline.json)에는 ID별 변화, 커버리지, 반복 시간, hash와 환경이 있다.
보존 열은 명령 성공을 뜻하지 않는다. 표의 명령 반환·기대 동작·롤백 열을 함께 확인한다.
보존을 실패한 결과는 배치 개선 후보에서 제외한다. ELK 채택·전면 재작성은 아직 결정하지 않았다.

## 실제 draw.io 확인

[비교 페이지](../2026-10-06-baseline/comparison.html)에 입력 4개 × 원본/계층/좌→우의 실제 SVG 12개를 연결했다.
SVG를 기본 scale=1의 원래 크기로 표시하고 각 창에서 스크롤한다. [렌더링 기록](../2026-10-06-baseline/rendered.json)과 [원본 화면](../2026-10-06-baseline/multi-az-original.png)을 보존했다.
v1/v2의 출력 XML 19개 SHA가 모두 같음을 확인해 이 렌더링을 v2에도 연결했다. [브라우저 이미지 검사](comparison-check.json)로 이미지 12개가 실제로 로드되는 것도 확인했다.
[비교 페이지 화면](comparison-page.png)도 남겼다. 사용자의 “보기 낫다” 판정은 아직 받지 않았다.

커스텀 style 키 `davinciBaselineProbe=keep-me`가 ECS 2개에서 XML 내보내기→파일 저장→그 파일 로드→재내보내기 후 보존됐다.
[원래 저장 파일](../2026-10-06-baseline/style-probe-first-export.drawio), [재로드 XML](style-probe-reloaded.drawio), [fetch hash·load 이벤트·키 검사](style-probe-reload-proof.json)를 연결한다.
이 결과는 임의 키 1개·그림 1개·해당 live draw.io 실행의 확인이다. 모든 메타데이터 키 보존을 보장하지 않는다. embed 버전은 export에서 제공되지 않아 미확인이다.
실제 SVG의 경로를 지표로 추출하는 기능은 아직 없다. 자동 측정 시점의 JSON에서 렌더링 경로 지표는 null이며, SVG 보존 후에도 측정된 것으로 승격하지 않았다.

## 왜 v2를 남겼는가

[첫 측정 v1](../2026-10-06-baseline/README.md)은 사각형 교집합 합계만 표시하고 명령 성공 열을 생략했다.
[Kiro 리뷰](kiro-runner-review.md)를 받아 부분/포함/동일을 분리하고, 명령 반환·기대 동작·롤백을 별도 표기했다.
측정 방법 버전을 2로 올려 **새 디렉터리에 실행**했다. 이전 숫자와 당시 해석은 덮어쓰지 않았다.
리뷰의 “완전 포함은 의도한 배치라 실제 겹침이 아니다”라는 추정은 채택하지 않았다. test2에는 동일 위치의 서비스 중첩도 있기 때문이다.
브라우저 재로드의 중간 근거도 파일 hash·fetch 상태·실제 load 이벤트로 보완했다.
