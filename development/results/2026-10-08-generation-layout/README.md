# B022 새 그림 배치 첫 개선

2026-10-08. 사용자가 테스트 숫자보다 실제 그림 개선을 원하며 계속 진행을 요청했다. 아이콘 수정 이후 같은 공개 입력(서비스 5·그룹 8·연결 4)을 고정해 전후를 비교한다.

목표: AZ는 나란히, 각 AZ의 퍼블릭/프라이빗 서브넷은 위아래 정렬. Cloud 소속이고 VPC 밖인 로그 S3는 별도 오른쪽 열에 배치해 좌측 아래의 긴 우회 경로를 줄인다. 아이콘·내용·소속·연결은 그대로 유지한다. 이는 명시적 타입/소속을 표현하는 배치 규칙이며 원본 좌표 복사가 아니다. 신규 생성 경로에만 적용하며 레거시 정렬 기본값은 유지한다.

완료 기준: 같은 입력 전후 XML과 숫자 보존, AZ/서브넷 정렬·경계·아이콘·선 경로 회귀, 기존 전체 테스트·빌드 및 KB 7페이지 스타일 참고 검사. draw.io 실제 화면은 기존 접근 차단으로 직접 검증하지 못하며 결과는 사용자 눈 판정과 구분한다. 기존 orthogonal 라우터만으로 해결되지 않는 선은 생성 시 waypoint를 준다. 완전한 교차 제거·전체 KB 품질은 이번 합격 범위가 아니다.

## 구현·최종 확인

Kiro Sonnet 5.5·medium이 생성 전용 tiered 배치와 제한적인 연결 라우팅을 구현했고 조율자가 독립 검증했다.


- [작업자 보고](worker-report.md). 레거시 옵션 기본값을 유지하고 새 생성만 서브넷 수직 배치·형제 그룹 크기 정렬·직속 서비스 오른쪽 열 배치를 쓴다. 서비스 스타일과 템플릿 크기는 유지한다. 임의 그래프 라우팅은 기존 draw.io에 맡긴다.
- 첫 구현 검사의 명시 경로에는 교차 3곳이 남아 있었다([중간 비교](comparison-initial.json)). 조율자 요청으로 로그 경로 후보를 서브넷 위쪽 틈새부터 시도하도록 보완했다. 최종 [전후 비교](comparison.json)의 지정된 XML 경로는 아이콘 관통 0·엄격 직교 교차 0이다. 같은 S3를 향한 공선 구간·합류는 이 교차 수에 포함하지 않는다. 수정 전 자동 경로는 좌표가 없으므로 미측정(null)이다.
- 서비스 5·그룹 8·선 4와 ID·라벨·소속·연결 일치. public/private 행·열과 AZ 너비 정렬, S3의 VPC 오른쪽 배치 통과. 전체 Cloud 경계는 1192×816 → 874×906: 폭은 줄고 높이는 늘어난다. 선 길이는 첫 후보보다 늘어난 2082px이며 최단선 개선이라고 해석하지 않는다.
- 조율자가 [전체 테스트](tests.txt) **22파일 321개**, [빌드](build.txt), [KB 7페이지 표현 참고·원본 페이지 보존 검사](after/proof.json)를 직접 실행하고 통과했다. 중간 after-initial은 최종 교차 보완 전 측정이며 최종 근거는 after다. 라우터 소스 해시도 포함했다.
- [수정 전 공개 그림](example-before.drawio)과 [수정 후 공개 그림](example-after.drawio)은 같은 공개 입력을 사용한다. 실제 생성 XML이며 화면 캡처가 아니다. 고객 KB 템플릿 결과는 private.local에만 보관한다.
- 사용자의 점진적 확인 요청에 따라 [Docker 반영](docker.txt)을 완료하고 [health·최신 asset](web-proof.json) 제공을 확인했다. 기존 생성 결과는 바뀌지 않으므로 웹 새로고침 후 새로 생성하거나 공개 draw.io 파일을 열어 비교한다. 실제 모델 호출은 하지 않았다.

## 남은 제한

직접 브라우저 접근이 차단되어 draw.io의 실제 글리프·선 표시·글자 폭을 확인하지 못했다. 위 측정은 지정된 XML 경로와 사각형이며 화면상 교차·라벨 겹침 전체 평가가 아니다. 긴 라벨 폭은 추정값, 임의 연결·여러 아이콘으로 통로가 막힌 경우는 자동 라우터 fallback이다. KB 전체 아키텍처의 품질 85~90%는 미측정이다. 작업자 세션을 유지했으며 워크트리 삭제·커밋·푸시는 하지 않았다. 다음 B020은 KB 관측 가능한 전체 구조 입력과 사용자 화면 평가로 이어간다.
