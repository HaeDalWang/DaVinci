# 0006 — 기존 서비스 줄과 함께 추가

2026-10-08. 상태: 구현·로컬 검증 완료, Docker 갱신은 사용자 보고, 실제 화면 확인 대기. 사용자는 기존 템플릿도 자연스러운 통합을 위해 변경할 수 있다고 명시했다.
기존 B008/B014의 위치 불변 기준을 새 작업의 제품 제약으로 적용하지 않는다. 예전 결과는 보존한다.
결정: 좌표 고정·가까운 빈자리만 탐색하는 대안은 같은 줄에 자연스럽게 끼워 넣으려는 요청을 만족하지 못한다.
따라서 관련 서비스 줄 재배치를 먼저 시도한다. 전체 페이지 재작성은 이번 범위보다 크므로 선택하지 않았다.

1. 기존 같은 서비스가 포함된 가로 줄을 찾아 새 아이콘을 끼워 넣고, 그 줄만 기존 간격으로 정리한다.
   아이콘 스타일·크기·이름·ID·부모·연결 source/target은 유지한다. 잠금 요소는 이동하지 않는다.
2. 계정/배경 내부·다른 영역과의 충돌을 확인한 뒤 좌표를 반영한다.
   줄 재배치로 해결하지 못하면 기존 빈자리 배치를 사용한다. 전체 페이지 재작성은 하지 않는다.
3. 합성 회귀 테스트와 실제 전체 KB 파일의 7페이지를 로컬에서 검사한다.
   변경한 좌표 목록을 기록하고 영향 없는 셀·다른 페이지를 검증한다.
4. 테스트·빌드 후 가능한 환경에서 실제 iframe·Docker를 확인한다.

현재 sandbox는 Orca 연결 EPERM, graph 도구는 승인 불가로 차단됐다.
위임을 수행한 것으로 기록하지 않으며 조율자가 로컬 구현·검증을 진행한다.
실제 브라우저/Docker 검증이 불가능하면 구현 검증과 운영 반영을 구분한다.
루트 PLAN.md, 고객 원본 파일, 과거 기준선은 수정하지 않는다. 모델 호출·커밋·푸시는 범위 밖이다.

[결과](../results/2026-10-08-row-reflow/README.md): KB 7페이지 로컬 보존·충돌 검사, 196개 테스트·빌드 통과.
서버 테스트 10개는 sandbox 포트 실행 EPERM으로 확인하지 못했다. Docker 접근도 차단됐다.
다음은 권한이 있는 환경에서 Docker를 갱신하고 실제 KB 화면·연결선·다운로드를 검증하는 것이다.
