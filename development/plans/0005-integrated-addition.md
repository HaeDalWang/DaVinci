# 0005 — 추가 서비스를 기존 그림에 통합

2026-10-07. 사용자 화면 판정: S3가 기존 구성과 떨어져 있다. 상태: 완료 — 기존 같은 서비스가 있는 경우.
현재 group 미지정은 항상 전체 그림 아래에 추가하고 카탈로그 기본 78px·색을 사용한다.
KB 기존 S3는 50px이며 같은 레이어에서 서비스 영역에 배치되어 있다.

1. 같은 서비스의 기존 아이콘을 우선 참고해 크기·스타일·부모 레이어와 가까운 빈자리를 사용한다.
   명시적 group은 우선한다. 영역 안에 있던 아이콘이면 새 아이콘도 영역 내부에 둔다.
   원래 요소·다른 페이지·연결·ID는 수정하지 않는다. 가능한 자리를 못 찾으면 기존 안전 fallback을 유지한다.
2. 시스템 프롬프트의 무조건 바깥 배치 안내를 수정한다. AI가 관계없는 VPC나 subnet을 임의 지정하지 않게 한다.
3. 합성 회귀 테스트·전체 테스트·빌드와 실제 KB 전체 파일의 개발 페이지 보존·위치·스타일을 확인한다.
   KB 데이터는 추가 모델 요청으로 제출하지 않는다. 로컬 실제 controller/iframe 검사를 사용한다.
4. Docker를 기본 프로필 실행 도구로 갱신한다. 사용자 Edge의 그림은 직접 바꾸지 않는다.

Kiro 소유: `src/core/diagram-controller.js`, `tests/diagram-controller-preservation.test.js`.
조율자 소유: 서버 프롬프트·검증 도구·개발 기록·Docker 확인.
커밋·푸시·전체 정렬·고객 라벨을 담은 공유 결과는 범위 밖이다.

기존 S3가 있는 4페이지는 50px·스타일·부모를 유지하고 60~72.12px 이내에 추가했다.
203개 테스트·빌드·Docker health 통과. 같은 서비스가 없는 페이지의 fallback과 실제 선·라벨 지표는 남아 있다.
