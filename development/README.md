## 지금 시작할 곳

1. [백로그](backlog.md)에서 다음 작업과 상태를 확인한다.
2. [첫 논의](discussions/2026-10-06-restart.md)와 [기준선 우선 결정](decisions/0001-baseline-first.md)을 읽는다.
3. [기준선 계획](plans/0001-baseline.md)의 다음 작업부터 진행한다.
4. 최신 필수 대상은 [KB 우선순위](discussions/2026-10-07-kb-priority.md)와 [KB 기준선·비교](results/2026-10-07-kb-baseline/README.md)다. 기존 4입력의 [v2 기준선](results/2026-10-06-baseline-v2/README.md)과 [초기 관찰](results/2026-10-06-initial/README.md)은 보존한다. 사용자 시각 판정과 일부 지표는 미완료다.
5. [서비스 추가 보존 수정](results/2026-10-07-preserved-addition/README.md)은 실제 KB 7페이지에서 통과했다. 사용자는 이 결과를 거의 완벽하다고 평가했다. B007의 실제 SVG 지표·B009의 보존 정렬과 새 그림 생성 품질은 아직 미완료다.
6. 최신 사용 흐름은 [Docker 웹 실행](results/2026-10-07-docker-use/README.md)이다. 8080에서 파일을 열고 다운로드할 수 있다. 모델 연결·실제 자연어 품질은 B011, 사내 배포 준비는 B012로 이어간다. 사용자는 서비스 추가 보존 결과를 “거의 완벽”이라고 평가했으며 이는 새 그림 생성 품질 검증과 구분한다.
7. 사용자가 승인한 기본 AWS 프로필로 [Sonnet 5.5·medium 실제 연결](results/2026-10-07-sonnet-live/README.md)을 완료했다. 빈 그림에서 실제 자연어 S3 추가와 다운로드, 189개 테스트·빌드가 통과했다. B013 완료이며 KB 레퍼런스 생성 품질은 B011에서 검증한다.
8. 사용자 화면에서 S3가 그림 바깥에 떨어진 문제를 [기존 배치·스타일 통합](results/2026-10-07-integrated-addition/README.md)으로 수정했다. 기존 S3가 있는 KB 4페이지는 50px·스타일을 맞춰 주변에 추가하며, 전체 7페이지 보존과 203개 테스트·빌드·Docker 확인이 통과했다. 같은 서비스가 없으면 기존 fallback이다.
9. 사용자는 템플릿도 자연스러운 통합을 위해 바꿀 수 있다고 명시했다. [관련 서비스 줄 재배치](results/2026-10-08-row-reflow/README.md)는 KB 7페이지 로컬 검사·196개 테스트·빌드를 통과했다. Docker 갱신은 사용자 완료 보고이며 B015의 실제 화면 확인은 브라우저 접근 권한 거부로 남아 있다. 과거 좌표 불변 기준을 새 작업의 제약으로 적용하지 않는다.
10. 사용자 S3 화면 평가는 “완벽”. Kiro 우선 개발 선호를 AGENTS.md에 반영했고 [S3 외 서비스 검증](results/2026-10-08-multiservice/README.md)을 Kiro가 수행했다. RDS 표기·줄 배치·뒤쪽 peer 탐색을 수정했으며 조율자가 225개 테스트·빌드·KB 28건을 다시 확인했다. EC2·Lambda의 실제 KB peer 경로는 미검증이며 추가 수정은 Docker 반영 전이다.
11. 새 생성은 **명시 입력·템플릿 표현·누락 질문** 방식에 합의했다. [계획 0007](plans/0007-reference-generation.md), [결정 0002](decisions/0002-explicit-generation.md), [B018 결과](results/2026-10-08-generation/README.md)를 따른다. Kiro의 첫 생성 경로와 조율자 301개 테스트·빌드·KB 7페이지 스타일 참고 검사·별도 이미지 health는 통과했다. 실제 모델·UI·전체 KB 생성 품질은 미검증, 현재 8080 서비스는 미갱신이다.

## 기록 규칙

- 착수: 해당 백로그를 찾고 없으면 먼저 추가한다. 큰 변경은 계획을 작성한 뒤 구현한다.
- 확인한 사실, 가설, 미결 질문, 제안, 합의한 결정, 실행 결과를 구분한다.
- 날짜와 관련 파일/명령을 적는다. 사용자의 말은 짧게 인용하거나 요약임을 밝힌다.
- 계획 변경은 변경일·이유를 남긴다. 결정 번복은 새 결정으로 연결하며 이전 근거를 지우지 않는다.
- 종료: 상태, 결과 링크, 남은 문제, 다음 작업을 갱신한다. 미완료는 미완료로 적는다.
- 원시 측정값을 나중 결과로 덮지 않는다. 비교는 같은 입력·도구·옵션으로 실행한다.
- 임시 파일·에이전트 화면만 근거로 두지 않는다. 필요한 결과를 이 저장소에 옮긴다.
- 고객 정보와 비밀은 기록하지 않는다. 저장소 기록의 원격 백업은 커밋·푸시 후에만 생긴다.

루트 [PLAN.md](../PLAN.md)는 사용자의 개선 원안이다. 이곳의 실행 계획과 구분하며 원안을 임의로 덮어쓰지 않는다.
새 기록이 미커밋 상태라면 다른 clone이나 새 워크트리에 자동으로 전달되지 않는다.
사용자는 2026-10-06에는 로컬 커밋만 요청했고, 2026-10-08에는 현재 작업의 커밋·푸시를 요청했다.
`drawio-sample/`은 사용자 지시에 따라 Git에서 제외한다. KB 원본과 `private.local/` 검증 자료는 로컬에만 남으며 다른 clone에서 KB 검증을 재현하려면 별도로 준비해야 한다.
원안의 `unknown`과 체크박스는 작성 당시 상태다. 최신 확인은 백로그와 결과 문서에서 찾는다.
기존 문서와 코드는 레거시 자료다. 새 구현은 사용자의 목표와 검증 결과에 맞춰 선택한다.

최신 사용자 생성 화면에서 AWS 아이콘이 색 사각형으로 나타난 원인은 공통 shape 필터의 camelCase 거부였다. [B021 수정](results/2026-10-08-generation-icons/README.md): 308개 테스트·빌드·KB 7페이지 참고 검사·Docker 웹 반영 완료. 화면 재확인은 새로 생성한 그림으로 진행한다.

[B022 새 그림 배치](results/2026-10-08-generation-layout/README.md): AZ·서브넷 정렬, S3 오른쪽 열, 로그 경로 보완을 Kiro가 구현했고 조율자 321개 테스트·빌드·KB 7페이지 표현 참고 검사와 Docker 반영을 확인했다. 같은 공개 입력의 전후 draw.io 파일을 제공한다. 실제 화면 품질은 사용자 평가가 남는다.

[B023 생성 여백](results/2026-10-08-generation-spacing/README.md): 사용자가 B022 화면을 “많이 괜찮아졌다”고 평가했다. 다음 생성 여백 축소·긴 그룹 이름 통로 보완은 조율자331개 테스트·빌드·KB 스타일 참고14건·Docker 반영을 통과했다. 사용자 화면 이름 공개 예제의 면적은39.4% 감소했고 지정 경로4개를 유지했다. B023 실제 눈 판정은 별도다.
