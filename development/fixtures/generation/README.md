# 공개용 생성 입력

`explicit.json`은 사람이 명시한 구조의 시험용 예시다. 고객 라벨·원본 좌표·원본 ID가 없다.
서비스 5개, 그룹 8개, 연결 4개를 정확히 생성해야 한다. 두 가용 영역과 각 public/private 소속·연결은 모두 입력에 직접 명시한 것이며 모범사례로 추정한 정보가 아니다.

같은 입력으로 카탈로그 기본 표현과 현재 템플릿의 표현을 비교한다. 레거시 KB 요약 입력과 다른 입력이므로 성공 건수를 직접 비교하지 않는다. 엑셀도 이후 이 공통 구조로 변환한다.

`screen-labels.json`은 같은 구조에서 사용자 공개 생성 화면의 AWS Cloud·Public/Private Subnet A/C·EC2 A/C·RDS A/C·로그 S3 이름을 사용한다. 긴 그룹 이름 때문에 연결이 자동 라우팅으로 돌아가던 B023 회귀 기준이다. 고객 이름이나 좌표는 없다.
