# 기준선 입력과 지표 — 방법 v2

입력은 [inputs.json](inputs.json)의 경로·SHA-256으로 고정한다. 기존 예제 2개와 측정용 합성 그림 2개이며 사용자 정답 세트는 아니다. 입력이 바뀌면 새 hash와 변경 이유를 기록한다.

- `multi-az`: ALB → ECS → Aurora를 AZ 두 개에 배치했다. 주 흐름 4개와 AZ 대응 노드 3쌍을 명시한다.
- `preservation`: 수동 위치·메모·미등록 AWS 아이콘·중복 라벨·waypoint·끝점 선과 연속 명령을 검사한다.
- 정답 그림 3개: 미확보. 사용자에게 고객 정보를 제거한 `.drawio` 예시를 요청한다. 합성 그림으로 대신했다고 쓰지 않는다.

## 측정 정의

| 지표 | 단위·범위 | 제외·미측정 조건 | 해석 |
|---|---|---|---|
| 구조 | XML 셀/vertex/edge/그룹 개수 | 한 페이지 비압축 XML만 지원. malformed·중복 ID·다중 페이지·압축 XML은 실패 | 그룹은 container=1 또는 실제 vertex 자식이 있는 vertex. AWS 의미 분류와 별개다. |
| 보존 | 원본 내용 셀 ID 누락과 공통 ID의 style/parent/value/geometry/끝점/kind 변경 수 | vertex/edge만 비교. 의도한 삭제만 누락에서 제외 | 누락·변경 0이 목표. ID 재발급은 안정적 ID 보존 실패이며 곧바로 같은 수의 객체 삭제라는 뜻은 아니다. |
| geometry 보존 | 정규화한 mxGeometry 표현 변경 수 | 속성 순서·숫자 표기·생략한 0은 동일 처리. 명시적 정렬은 geometry 변경 허용 | 서비스 추가는 기존 좌표·크기·선 표현 변경을 허용하지 않는다. style은 문자열 비교라 순서만 바뀌어도 변경으로 기록한다. |
| 사각형 교집합 | 양의 면적으로 만나는 vertex 쌍. 부분/완전 포함/동일 사각형을 상호 배타적으로 분리 | XML의 조상/자손 쌍, 경계 접촉 제외. 라벨·아이콘 실제 윤곽 제외 | 세 개를 품질 점수로 합치지 않는다. 포함이 사용자 의도라는 뜻은 아니며 동일 좌표의 아이콘도 숨기지 않는다. |
| 좌표 커버리지 | 측정한 vertex/전체 vertex | relative·회전/skew·offset·누락/잘못된 geometry·해석 불가 부모 제외, 자손으로 전파 | 부모 상대좌표를 절대좌표로 합산. named style의 간접 회전은 해석하지 못하므로 사각형 근사임을 유지한다. |
| 면적 | 측정 가능한 vertex 전체 경계 상자, diagram unit² | 측정 vertex가 없으면 null. 정답 면적 비율은 미측정 | 정보 손실·커버리지가 다른 면적을 직접 비교해 개선이라고 판단하지 않는다. |
| 선 표현 | 셀 source/target 둘 다·한쪽·없음, sourcePoint/targetPoint/waypoint 존재 수 | 실제 렌더링 경로로 취급하지 않는다 | 선이 없어지면 교차 0으로 채우지 않는다. |
| 교차/관통/라벨 겹침 | 현재 null | XML 측정기에 렌더링 경로·라벨 범위 해석 기능 없음 | 실제 SVG는 보존했지만 해당 지표 추출기는 아직 없다. 후속 작업 B007에서 측정한다. |
| 역방향 주 흐름 | 명시한 horizontal 주 흐름의 source 중심 x가 target 중심 x보다 큰 선 수 | 명시 흐름 없음·ID/좌표 대응 누락 시 null, 커버리지 표기 | 합성 입력의 0은 기준 입력 값이다. 아직 vertical 흐름은 정의하지 않는다. |
| AZ 대응 편차 | 명시한 대응 노드의 AZ 부모 기준 위치 차이, 평균 L1 거리(diagram unit) | 대응 ID/부모/좌표 누락 시 null | 전체 AWS 대칭 점수가 아니다. 합성 입력의 명시 대응 위치만 비교한다. |
| 명령 정확성 | 기대 성공 여부·추가 셀 수·의도한 삭제·보존·롤백의 합격 여부 | 실제 컨트롤러 + 메모리 get/load 어댑터. iframe merge/AI 실행 미검증 | 성공 반환과 합격은 다르다. 의도한 실패의 정확한 롤백은 합격이고, 성공해야 할 명령의 롤백은 실패다. |
| 실행 시간 | ms, warm-up 1회 후 5회 min/median/max와 원시 값 | 파싱·재구성·XML 생성 또는 컨트롤러 실행만. 측정기·IO·렌더링·네트워크 제외 | 경고 수집 계측 포함. 같은 환경·방법끼리 비교하며 다른 기기의 값은 직접 비교하지 않는다. |

## 재실행

저장소 루트에서 의존성을 설치한 뒤 아래 명령을 실행한다. 출력 디렉터리는 새 이름이어야 한다.

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm test
node scripts/measure-baseline.mjs development/results/<새-측정-이름>
```

입력 hash가 다르거나 출력 위치가 이미 존재하면 실패한다. 제품 보존 실패는 기록할 관측값이며 측정 도구 실행 실패와 구분한다.
